Reach Defence builds Vector Engagement Labs. It is a browser-based laboratory for engagement experiments. Each run shows its assumptions, synchronized simulation views, comparisons and reproducible reports.

This site has two parts.

- **[Architecture diagrams](architecture/overview)** show how the system operates. Each diagram is data in this repository.
- **[Contracts](contracts)** are the maintained engineering contracts. Each build copies them from `vector-lab/docs`. Edit the contracts in the vector-lab repository only.
