Each side has its own picture of the engagement. The picture uses only admitted sensor models and tracks that the side owns. It does not use model truth. The deployed reference pack has no positive-range sensor model. Thus, production runs report `UNSUPPORTED`. A pack for engine verification only tests the track mechanics below.
