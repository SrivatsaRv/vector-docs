The compiler changes human-readable model sources into immutable, SI-normalized, content-addressed model packs. This occurs before an engine starts. Each run becomes a VECTOR Simulation Record (VSR). A VSR is a portable archive. Replay and debrief use the VSR and do not run the physics again.
