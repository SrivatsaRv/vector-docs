In production, a stateless Cloudflare Worker serves the application. Simulation runs stay in the browser. The Worker connects to PostgreSQL/PostGIS through Hyperdrive. Deployment does not build the application again. It promotes one exact Worker candidate that a green `main` CI run tested.
