The Construct stage makes one immutable scenario package. The compiler resolves the package. A fixed-step engine in a dedicated browser Web Worker moves each declared entity. Map, 3D, telemetry, RASP, explanation, comparison and reports read the same recorded frames. These consumers do not write to the engine.
